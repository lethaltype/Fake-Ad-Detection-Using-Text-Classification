The Problem & Solution
⚠ The Problem

Car dealers on PakWheels routinely post ads posing as private sellers — misleading buyers with inflated prices and hidden commission fees. Spotting them manually is tedious and unreliable at scale.

✦ The Solution — Carzio

An AI-powered mobile app and web platform. Paste any PakWheels listing URL, and the NLP + ML pipeline analyses the seller's comment text to instantly return a verdict: Genuine or Dealer.

End-to-End Pipeline
01

User pastes a PakWheels URL

Into the Carzio mobile app (Flutter) or web browser. A POST request is sent to the Flask API's /link endpoint.

Flutter App Web App
02

Web scraper extracts seller comment

Python Requests + BeautifulSoup parses the listing page HTML, extracting the seller's written description — the primary feature for classification.

BeautifulSoup Requests
03

NLP pre-processing pipeline

7-step pipeline: lowercase → punctuation removal → number conversion → whitespace strip → stopword removal → stemming (Porter) → lemmatization (WordNet).

NLTK inflect
04

N-gram TF-IDF vectorisation + Naive Bayes

Bigram & trigram TF-IDF (max 5,000 features) transforms clean text into vectors. The trained Naive Bayes model predicts the label. Model serialised via joblib.

Scikit-learn TF-IDF
05

Result returned instantly

Flask /results endpoint returns JSON. The app displays Genuine Seller or Dealer Detected to the user in real time.

Flask API JSON response
